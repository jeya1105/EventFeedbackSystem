# Level 1 – Frontend Pages

## Project Title

FullStack Event Feedback Management System

## Objective

The objective of Level 1 is to create the basic frontend structure for the Event Feedback Management System. The frontend provides a user-friendly interface for viewing events and submitting feedback.

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- React Router

## Tasks Completed

### Task 1: Homepage

Created a homepage for the Event Feedback Management System.

The homepage includes:

- Website title
- Short description about event feedback collection
- Clean and user-friendly layout

The homepage introduces users to the purpose of the application.

### Task 2: Navigation Menu

Implemented a navigation menu to allow users to move between different sections of the application.

Navigation links include:

- Home
- Events
- Feedback
- Submitted Feedback

React Router is used to handle navigation between the frontend pages.

### Task 3: Events Page

Created an Events page that displays sample events.

The page provides users with information about available events and allows them to view the event details before submitting feedback.

### Task 4: Feedback Page

Created a Feedback page with a feedback submission form.

The form contains fields for:

- Name
- Email
- Event
- Rating
- Comments

Basic form validation is implemented to ensure that required information is provided.
